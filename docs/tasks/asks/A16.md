# A16

**Status:** in flight (2026-11-10, opus-preflight)
**Ask:** "Queue pre-flight, yeah, sure, do it. Fucking cheap 5 seconds check before in queue." (meta DEV-SPEED-PLAN row DS16c)

`push-queue.mjs enqueue` runs `scripts/push-preflight.mjs` before it
captures a job. It refuses, in seconds, what the full gate would bounce
on bookkeeping: new test files with no committed clock, a new test file
the gate wholly skips, and commits that conflict with origin/main on the
queue's rebase (`test/durations-source.json` included). Stale stamps and
the journal rule only warn: the queue regenerates stamps itself and runs
no pre-commit hook. `WS_PREFLIGHT_SKIP=<reason>` overrides, logged in the
job record and the lane receipts.
