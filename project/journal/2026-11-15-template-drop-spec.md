# The Template suite survives a real socket drop

The Template MMO fixture uses the existing FM chaos proxy on owned
loopback ports. Its two named pages remain seated for the worker. A
matched drop cuts their actual sockets, refused upgrades hold the gap,
and the real drop strip appears. Healing clears it; a new rendered frame
and chat received by the other page prove recovery.

Only console errors describing the deliberately refused loopback socket
are allowed for this fault; page exceptions still fail. Healthy bodies
and chat remain strict. Both checks pass on one boot in 31.0 s. All proxy,
release, world and page resources close at worker teardown.
