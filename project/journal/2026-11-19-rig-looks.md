# Rig looks (ONE-FORMAT OF19d2)

- 2026-11-19, opus-of19b5: format 0.50.0 lets a look row name a scene
  model library's rig (`platform.rig`, `{ library, body? }`). The page
  now draws it: `loadClientRigLooks` preloads each named library's rigs
  before kit (the same library the world's scenes prepared), and
  `clientSpeciesLooks` resolves the look to the library rig whose kind
  is the row's body, else the species' kind.
- A native page with no `species.program` now marks its species as
  registered from the declared rows, so `population.homes` installs.
  That is what lets Sunscar Dunes drop its last species program (OF19d).
