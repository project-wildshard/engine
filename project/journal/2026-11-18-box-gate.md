# The box workflows get their own key

MA7c (meta MINI-AUTONOMY-MACBOOK) narrows what the box workflows can do.
They used the agents' key, whose sudo list also restarts production and
runs rebuild.sh, so any run from main could reach past the probe and the
staging restart. Now they get a key of their own, on a second line of
root's authorized_keys file with `restrict` and a forced command. The
gate, `wildshard-box-gate`, runs a hex-encoded loopback Prometheus query or
the staging restart and refuses every other ask, a production restart
included. The secret swaps once a signed release puts the gate on the
box; until then box-ops falls back to the plain commands on exit 127.
