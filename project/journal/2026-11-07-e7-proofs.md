Carry the dedicated outer-boundary tests and their real socket,
Postgres/PGlite and pinned-product fixtures. The existing E7 run
passed 120 tests across the dedicated, VPS and online-shell files.
The later reward/rider proof passes four tests in 4.79 seconds.

The reward proof first reproduced epoch-zero admission, a refused valid
reward document and a retained lead identity. It now earns and claims
a real ghost-stag finish, checkpoints, restarts into an added seat,
and checks that both lead and added identities are removed on leave.
Malformed reward records remain refused. Nalati's live mounted player
keeps its seat during export and imports on foot in a fresh room.

The socket-room parity proof loads complete product files, like the
existing net-bots proof, so it belongs to Ring 2. Dedicated server
proofs use the server-only product reader and stay in the normal lane.
The handshake fixtures now generate public nonces. Local PostgreSQL
URLs are constructed from explicit host, user and database fields;
the public-tree scanner needs no new allowlist entries.
