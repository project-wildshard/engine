# Count the wire population in one pass

The Driftwood phone Low dock profile sampled work in the creature
counts. Each requested species walked the entire entity map, and
the projection enumerated its declared count rows again on each
update.

Build the requested kinds once. Fill those counts in one pass over
the latest frame's living, relevant rows, then publish the authored
IDs from the reusable results. The real room proof covers a death,
a missing kind and clearing the results when the wire is absent.
