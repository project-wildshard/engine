Port the net core from e7-early 434fd8d0867fe4352a18d2c6e44579daa446f25e,
whose tree also contains E7-PHONES. The source clone's commit matches the
e7-full bundle tip. Read its objects without importing monolith history
into this public repository. Map layer-first paths to engine's side-first
layout with the lift kit's pure mapping helpers and a three-way merge.

Keep the engine's death notifications while adding reconnect listeners,
socket framing, late-join state and player rejoin behavior. Runtime ws
and pg dependencies are declared here; PGlite is test-only. PGlite's
socket package requires its seven declared peers under strict installs.

The socket keepalive proof reproduced a timing race: its silence timeout
equalled its ping period, and the server still had zero RTT. Wait for
both measured round trips with a bounded deadline and leave a second
of silence margin. The real socket-room file then passed all 8 tests.

scan. Subsequent commits still select explicit named paths. Use the
