# Play production heads before signing an engine release

The exact release cooks admitted Pine r5, Driftwood r4 and Nalati r2. Room
replay then held v0.1.79 at 24/26 and v0.1.80 at 23/26. The stored check
can admit an unmeasured native world, so it cannot answer whether that
world starts or ticks.

Before signing production, replay each advertised raw head through
admission, the actual room loader, and 600 room ticks on the release
checkout. A changed catalogue or a named refusal stops signing. The
staging artifact and npm next workflows continue independently.

The replay tests use the existing tooling suite. This keeps the new
check out of the shared test configuration and its broad push selection.

Use the same platform item catalogue as the signer. A room validates its
ledger rewards against that catalogue, so the play check needs those rows.
