# OFF-VERCEL OV6: preview on Workers

- `preview.yml` runs `page-release.mjs preview build,upload,check,go-live --host=workers`
  (Worker `wildshard-play-preview`) in place of Vercel's prebuilt deploy and prune.
  The change-skip stays and also watches `pages/` and the release scripts.
- The solo preview's carry-over treats a 5xx at its own origin as no previous builds:
  the first release had to build while Vercel's paused preview answered 503, and a
  staging or production release still refuses.
- Codex review (no MUST): the job's timeout drops to 55 minutes so the next hourly run
  never cancels a finished-but-slow one, sentry-maps gets back its 5-minute cap inside
  the Workers host, the change-skip watches `src/server` (the solo page bundles the
  server worker), and `previousDeployOptional` is a tested function.
- A new Worker refuses `wrangler versions upload` ("does not yet exist"): the first
  preview version went up with one `wrangler deploy --env preview` (no domain, so not
  reachable): 8,375 files, 2.4 GB of dist, 2 min 52 s from the MacBook.
