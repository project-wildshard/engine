# Far Reach graph data maps cook losslessly

Far Reach's storm noise and sward atlas name graph texture parameters
with a data role. The SDK lowers these graphs into JSON blobs, so the
cook reads the declarations from the packed file. The PNGs then use the
same lossless route as the ground's data slots. The regression uses a
hash shared by colour and data and checks both tiers reference the
byte-exact data texture.
