# Browse staging zones in Explore

> Written by: Codex
> State: EX3, 2026-11-19 (J461, J468)

The root draws the installed staging catalogue without opening a world.
Once the Zone Select endpoint answers, its card order and names update
the list. The build's visible placements stay available when the API is
unreachable, and open plots stay out in both cases.

The browser proof uses the staging pin snapshot and a response fixture
for the J461 endpoint, which hasn't deployed yet.
