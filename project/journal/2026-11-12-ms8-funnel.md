# MS8: the Funnel retires

- MS8.2 (opus-ms8): Jake played on `wss://rooms.wildshard.io` (MS7.4), so the
  Funnel goes (meta MMO-SERVER-PLAN D3). `setup.sh` makes the 443 and 8443
  health routes tailnet-only Serve instead of Funnel; `setup-state.mjs` calls
  any `AllowFunnel` true drift and names `tailscale funnel --https=<port> off`.
  Surprise: `tailscale funnel ... off` removes the whole route, not just the
  public flag, and the release gate (`page-release/flow.mjs`) and the staging
  proofs read `/health` over those tailnet HTTPS ports, so a setup rerun after
  the off commands puts them back as tailnet-only.
