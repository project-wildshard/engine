# Installed TypeScript on Node 26

RELEASE-BRANCHES RB6a2b: the kit's real SDK proof reached its installed
RNG import after the ARM64 compiler fix, then Node 26 refused native
TypeScript transform mode. Probe support once, retain Node 24's native
path, and lazily use the existing shipped TypeScript 6 dependency when
the runtime has removed transform mode. Enums and parameter properties
keep working; the hook still admits only our installed packages.

A real installed-package regression covers typed exports, an enum and
a parameter property, plus refusal of a foreign raw-TypeScript package.
It is run with Node 24 and a checksum-verified official Node 26 binary.
