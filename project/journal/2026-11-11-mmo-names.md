# MMO names (MMO-PLAN MP2.4)

- Names are unique with a tag (Q31): the door claims `(lower(name), tag)` in `player` (migration 0004, additive) before it
  seats anyone, and everyone reads `Name#1234`, in chat, on bodies and in voice. A player keeps the tag while they keep the
  Name; a new Name draws a new one. Eight random draws, then a read of the free tags; a full Name throws (`NameFullError`),
  which the door turns into a `retry`.
- A save no longer renames a player (`WRITE_PLAYER` only touches `seen_at`): the Name is the claim's.
- `cleanName` now refuses a Name with a listed word whole (it reads as Guest) rather than starring it, so no part of a refused
  Name reaches another client. The room takes the door's Name through `NetWorld.nameOf`, never the hello's.
- `memoryPlayerSaves` has no `name`, so soaks and bots on memory saves keep the typed Name.

## Global chat (MMO-PLAN MP4.1)

- No wire change: `room` now means the world. `RoomChat.say` hands each `room` line to a `shout` hook; the dedicated room posts
  it to its worker, the door sends it to every worker, and each worker gives it to its awake cells but the one that said it
  (`RoomChat.hear`). It arrives as a line from nobody the client can see (`from` 0), the same as a speaker out of view.
- The filter and flood check run once, where the line was said. A heard line is kept like a local one, so a report from another
  cell still holds what was typed. Proximity never leaves its cell.
