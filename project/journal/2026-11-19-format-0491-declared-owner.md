# Engine pins format 0.49.1 (OF20c)

> Written by: Claude (opus-of-close2)

Sky Reach's Storm Roc is a declared boss encounter beside its runtime plan, and the plan keeps its owner row so the
engine (ffe31ce9c) hangs the flag, fact, purse and save on that encounter. Format 0.49.0's client ownership rule still
asked the page for a `boss.held` feature whenever the plan had an owner row, so admission refused the moved product.
Format 0.49.1 drops that ask when the owner row names a declared spawn with a boss encounter; the engine pins it so a
release can admit Sky (and Dunes' Matriarch, OF19c1) without a keeper fight on the page.
