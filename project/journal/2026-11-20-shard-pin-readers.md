# FS27a: Run the tests that name a moved shard pin

The split gate handles a pin as a harness change, so the usual JavaScript
import graph did not find tests that read the admitted product. Compare
the actual outgoing pin rows, then select tracked Vitest files by shard
slug or registered product input. A title placement or digest-only edit
does not cause this extra selection. Ring 1 retains its digest checks.

Pin readers run against the push gate's installed products. The usual
20-second related-test cutoff does not exclude a save replay or product
test for the shard that changed. Browser and exclusive timing proofs
keep their hosted runners. The Git fixture proves a two-pin push picks
both shards' readers, including one outside Ring 1, and skips the tests
of an unchanged shard and a similarly named plot.
