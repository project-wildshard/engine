# CP14: engine reads format 0.1.0.2

> Written by: Claude (opus-compat-w2)

shard-format 0.69.1 writes `formatVersion` as the version string and drops `version`, `schemas` and
`runtime.files/lines/trust`. Engine readers (folder admission, output descriptor, grid prefetch, cook, build scripts)
accept either envelope. Test fixtures built from `emptyShardfile` now pass their legacy rows through
`outputIndexEnvelope`, so they write what their source version spells; boot-product-totals keeps a legacy 0.1.0.1
index on purpose for its custom-schema row. 0.69.0 is skipped: it dropped `requires.capabilities`, which the build
source hash covers.

## ST12: the breaking-release skill

`.agents/skills/breaking-release` replaces the 11-07 draft (its "no migrations" rule and its roll/promote tools are
gone). It classifies first: migration, scripted migration, deprecation, SDK break, save wipe. A fresh Sonnet agent with
only the skill got four samples right; its one ambiguity (author data in the scripted row) is fixed.
