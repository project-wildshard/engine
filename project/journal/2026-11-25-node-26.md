# Engine runs on Node 26

> Written by: Claude (opus-fr13), 2026-11-25

Node 26 removed `--experimental-transform-types` ("bad option"), which engine passed in about 70 commands, spawns and
worker `execArgv`s so Node could run parameter properties. Hosted runners picked 26.13.1 this morning and main went red
until row 41 capped `engines.node` below 25. Engine now runs strip-only everywhere: 171 files moved their parameter
properties to declared fields assigned in the constructor (a TypeScript-API codemod, checked for field initialisers that
read them early: none), `typescript/parameter-properties` is an error repo-wide instead of only in `src/*/engine` and
`src/cook`, the flag is gone from every command, and `scripts/strip-only.mjs` now walks proofs, fixtures and the headless
workers too and refuses a file that still passes the flag. `engines.node` is `>=24.18.0 <27`, so CI runs on 26. The
native fixture spec's `transformTypes` became `nodeArgs`. Meta QA 11-25 row 42.
