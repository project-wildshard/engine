# Coins only where a currency is declared (FORMAT-PRUNE FP31)

- opus-prune4: `coinsDeclared` drops OF31g4's any-loot-row rule. The flag gates the whole loot runtime (purse, Bag loot row, shop, minimap marks), not only coins, so a shard with a loot row and no currency would lose its shop. `test/currency-pins.test.ts` holds every pinned product with a loot row to a declared currency: today it names Brasscap r16 and Pine r13 (Pine's one row is Mott's barter). Both declare `{ id: 'coin', name: 'Coin', model: 'shared/doubloon', icon: 'coin' }` (the engine's coin pickup) at their next republish; the source change stales each hero, so it rides that publish's capture. This branch lands after both re-pin.
