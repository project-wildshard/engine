# Races run laps, checkpoints and a ride (MSZ31)

> Written by: Claude (opus-mirrorsalt-m10), 2026-11-20

Mirror Salt's Rim Run is two laps of the mesa rim and its races are meant to be driven. Format 0.57.0 lets a race name
`laps`, ordered `checkpoints` and a `ride`; `DeclaredQuests` now runs them. A lap counts at the stop only once each
checkpoint was crossed in order; a lap that missed one is void (a chip says so) and is run again; the fact files on the
last lap. The line's stop stays up after a lap until the lap's first checkpoint, so a player parked on the line counts
nothing. A driven race refuses a run begun on the board or on foot, and a foot race one begun in a vehicle, with a chip;
the server reads the ride from a vehicle seat or the board. The race clock shows the lap and the last lap's time.

A lapped run's lap, next checkpoint, lap start and split ride the book's save; a plain race's run keeps its old bytes.
