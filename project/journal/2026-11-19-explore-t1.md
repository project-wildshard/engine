# Explore runs through the Ring 1 browser gate

> State: tested locally 2026-11-19.
> Written by: Codex

Run the actual Explore build with Signal Dunes in hosted CI. The browser follows
its zone card, holds W until the camera moves, opens a model and returns to the
list. It records WebSockets, durable save keys and databases, and gameplay
notices that briefly appear while the viewer loads.

The first browser run found that bootstrap cleared the free camera's held keys
each frame along with the parked player's inputs. Explore keeps its own input
context live. The Dunes' quest notification and reward caption also appeared
during boot. The public viewer leaves those surfaces off while the NPC
presentation and server keep running.
