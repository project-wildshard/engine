# Green cut

Velocity lane (opus-velocity, meta QA 11-25 row 67). The v0.1.92 train waited on 9a5101633, the Driftwood r13 pin commit, but main ci had cancelled that commit's pending run when the next land arrived, so it would never get the green run of its own that provesTrainCi needs. `scripts/green-cut.mjs --contains=<sha>` prints the newest main commit with a green ci run of its own that carries the given commits, or the oldest run still going. Trains cut there instead of waiting on a cancelled sha.
