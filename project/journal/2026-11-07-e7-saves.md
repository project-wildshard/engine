# Durable E7 player stores

Port E7's PostgreSQL migrations, write queue, report queue and portable
PlayerDoc. Current/previous copies and receipt recovery stay intact.
Map imports to the side-first host without importing source history.

REVIEW-4's reward key is an explicit PlayerStore allowlist entry and a
defined save slot. Admission validates its schema, so a corrupt reward
record is refused rather than silently replaced. Recovery also filters
finish grants out of pack inventory.

The dedicated/VPS/online-shell run passed 120 tests in 22 files. The
new four-test reward and rider proof passes in under five seconds:
epoch zero refusal, slot admission, earned-and-claimed Pine rewards
across process/seat changes, and a live Nalati rider checkpoint that
restores on foot without changing the active rider.
