# Native harvest bindings

> Written by: Codex
> **State:** built, 2026-11-16.

Bind admitted harvest declarations when existing native rosters attach
bodies and when species homes construct policies. Pine reads its native
rows; Driftwood reads both native fauna and species-program rows. Fresh,
replacement and restored actors cross the same existing attachment seam.
The metadata stays outside saved simulation recipes and native wire
labels; old undeclared bodies retain their prior harvest law.

Sixteen focused native lifecycle and harvest cases, full types and game
lint pass against candidate format edf5464. Exact published product pins
and retirement of the old harvest table remain OF31b3b2.
