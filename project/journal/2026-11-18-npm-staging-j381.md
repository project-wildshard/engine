# Admit the named staging runner queue exception for npm next

The v0.1.44 release branch passed its required jobs except for the hosted
memory-footprint guard, which lost its runner queue before any step ran.
The release uses J381 for that cancelled attempt and keeps the full
candidate QA, public page readback and the signed rooms check.

The npm next job uses green release-branch CI first. With the pre-alias
verdict it can verify the named J381 attempt from GitHub. A job that ran
any steps, failed a check or falls outside the two memory guards still
blocks publication. This admission applies to the staging dispatch.
