# Let an authored shard open the viewer without custom art

> Written by: Codex
> State: EX6 engine prerequisite, 2026-11-19 (J460)

The published v0.1.50 dev client reached the authored shard's title
after its name prompt. The inline folder advertised the Explorer in
its capabilities and supplied a standard zone card. It had no separate
Explore art, which the deep link required.

The explicit viewer request now takes the authored capability and uses
the zone card for the hub. The packed reference CLI with the locally
built client reached Explore, rendered frames and read 374 authored
sections in the outside-browser proof.
