# Engine on shard-format 0.12.0 (SHARD-SOURCE SS8, SS9)

`plan/ss16l` moves the format pin from ^0.7.0 to the released 0.12.0, which carries `look.light.swings` (SS8c) and
`props.bodies` (SS9b). Typecheck needed two things: an export for `world/swings`, and the journal icon rule, which 0.11
widened to a glyph or an image. Image icons are engine `plan/one-format-m1`'s to draw; until it lands a glyph rule alone
names an icon here, and whichever branch lands second keeps one-format-m1's resolver.
