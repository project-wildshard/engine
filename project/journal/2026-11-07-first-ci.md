# What the first runner found

The lift's Mac held everything a fresh runner doesn't, so the first CI run on this
repo found what no rehearsal could. Three things, all fixed here.

The `check` job never installed pins. Tests read pinned products, and the Mac had
them from the lift, so pre-push was green and a runner failed 127 tests in 68 files.
`check` now installs them, as Ring 1 does, with room for a whole suite.

The kit pinned `@playwright/test` at 1.60 and singleplayer pinned `playwright` at
1.65, and Playwright refuses every test when the two differ. No rehearsal ran
`test:e2e`.

Eight test files need whole heads for Pine, Nalati, Driftwood or the full grid, and
landed after `ring-2-tests.json` was written. They pass on all 28 pins and fail on
Ring 1's three products and slices, so they're Ring 2's. `check` still runs them on
every push.

`ring-digests.json` gains its Linux baseline, recorded by `ring-1`'s record run, now
the `pins` release exists.
