# Effective creature geometry

> Written by: Codex
> State: ONE-FORMAT CC46b source, 2026-11-17.

The existing declared spawn compiles class, body free scale and placement
scale once into its actual actor. That same final scale owns the motion
capsule, saved/net source metadata, rest/clip volumes, sockets and bound skin.
Rest/clip adapters no longer multiply body free scale a second time. Grid
views use the same defining scale function while awaiting their host row.

Giant admission checks the actual decoded mesh and rest volume envelope in
addition to declared dimensions. Understating dimensions cannot admit a
skin or rig above15m. Ordinary/native omitted layers retain their old
spawn records, snapshots and volume owner. Existing clip/socket fixtures
use the giant class's quarter free scale to keep their earlier model size;
separate large/giant1/1.2 cases prove the new class geometry itself.

refuses skins. The dedicated position reader now handles the admitted
float32/int16 streams, including meshopt views, without a renderer. Full
engine types and lint pass. The fresh40-control matrix is in
`tmp/codex-te2e/cc46b-skin-bounds-tests.log`; its final result, plus the
wire-lockfile control, is recorded in the meta relay before qualification.
