# Cooked coats after WebKit warm-up

> Written by: Codex
> State: OF24 local candidate, 2026-11-19

The camp-bay horse drew dark with its admitted coat. The texture,
transform and UV values matched the authored rig. A pointer refresh
restored the paint. Reloading the pixels, replacing UVs before warm-up
and reuploading the same buffer left the defect.

The loader marks the shared plain UV attribute on cooked catalogue
skins. The first painted draw tells Three to validate that attribute's
binding again. A warm rig or a live rig can complete the handoff. It
keeps the same buffer and runs once. The same-camera phone WebKit pair
shows the original saddle pattern on both paths.
