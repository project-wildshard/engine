# FM2 real loopback fault instrument

The user assigned the missing proxy after FM3's review. Build this
prerequisite independently: it has no UI or numbered scenario catalogue,
no backend/wire changes and no live service target. The public CLI/control
contract is chaos-proxy/1 with the agreed 13 fault kinds.

Use an exclusive owned 0600 token, validate the complete replacement before
activation, and record actual matches/byte counts. Learn pack/member URLs
from real book/manifest bytes. A corruption rule damages binary payload,
not JSON, and leaves HTTP length honest so the client's existing admission
can reject it. Do not confuse a network reset with hash/length refusal.

Rules reach existing sockets. Delay and bandwidth maintain message order
and bounded native backpressure; heal releases pending waits and resets
old delivery deadlines. Half-open drops are never replayed on healing.
Seeded loss touches only binary prefix 1. The native proof preserves real
reliable/control and voice-prefix-8 bytes through the upstream echo.

Three real CLI/upstream checks pass in 0.94 seconds after independent
format, scripts types and typed lint checks. They exercise every kind,
HTTP and WebSocket bandwidth, genuine TLS with a trusted fixture cert,
late activation/1006 termination, native coded close, token refusal,
atomic invalid/oversized controls, external/symlink/bind refusal, healing
and parent EOF. No game browser or full-suite lease is needed for these
controls. The first draft's send callback treated native null as failure;
the real echo caught it and the callback now preserves native success.

This is local source pending J206 and the normal full publication gate.
No hosted or FM3 baseline pass is claimed. The proof is self-contained and
imports no unpublished FM3 helper; its dependencies already exist on main.
