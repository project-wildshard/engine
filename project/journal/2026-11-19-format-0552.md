# Keep declared boss decision fields

ONE-FORMAT OF22c2 moves Driftwood's Captain out of the runtime boss
spawn list. The declared spawn and its boss encounter keep the public
decision fields used during the fight.

The copied Captain regression failed on shard-format 0.55.0 with
`runtime-bound state supports host fields and retained-actor numeric
fields`. Engine pins the published 0.55.2 fix. The shipped Driftwood
fixture still exercises the chapter wake, fight and restore paths.
