# Store zone files once in the cooked bucket

The versioned publisher restores raw mounts for the zone's URLs. A mount
or loose product file already in a client or server part now keeps an
index entry pointing to the member's offset and digest. The page, road
bake, and server worker verify that digest when they read the member.
Direct title images keep a loose URL and stay out of the client pack.

The test opens real Brotli parts and compares each member's digest with
every loose file in the cook. A fresh Brasscap Mesa cook published 28
objects and three packed aliases. A road fixture rejects a corrupt part
member. The versioned layout is cook 1.4.0.

The zoneless page validates staged baked textures before stripping zone
files. Its browser proof uses the normal Zone Select tap. The page calls
browser fetch with its normal receiver, so Chromium can install the
cooked index.
