# The server's primitive list (ONE-FORMAT OF17b1)

`hostPrimitives.ts` works out which primitive families a host runs at
load: format `derivePrimitives` over the product's section payloads,
plus, until M8 empties `server/native-assembly.json`, the family each
native feature joins (`primitiveOfHost`). `primitivesOf(host)` reads
it. Nothing installs from the list yet; it is the list OF17b2/b3 and
OF1's count read. The Template's own source no longer lives in engine
(its fixture imports a removed folder), so the test uses a plain
declared fixture and Driftwood's native plan.
