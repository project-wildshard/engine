# Open an Explore view through its link

> Written by: Codex
> State: EX4, 2026-11-19 (J460, J463, J468)

A single-segment path picks the zone and leaves the view query in the
address bar. The MMO's explicit Explore link redirects to the dedicated
app. A cached MMO shell gives that navigation back to its Worker.

The preview build still accepts its deployment verification key. The
solo-channel guard rejects a world URL, which actually selects a world.
