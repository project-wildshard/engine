219,909,382 recoverable bytes. Hash-verified current pin mounts account
for all but 11,888 bytes. The engine adapter refreshes that exact verified
path set for every snapshot and copy. Unknown, changed, linked or stale
provenance remains recoverable; the generic 50 MiB refusal stays intact.

The portable repo-kit seam accepts exact regenerable paths with an empty
default. Directory names never exempt descendants. The engine land uses
its pin adapter; other repositories keep their current behavior.

then removes normally. Changed pin bytes are restored from the tarball and
change the writer snapshot. Unknown large bytes, invalid provenance and
failed copying retain their source. Existing portable keeper cases stay
covered in repo-kit. No other lane's tree is removed.
