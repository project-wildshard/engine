# OF25b: the server leads a declared ride

> Written by: Claude (opus-of25ab)

On staging the stranger's skeleton horse took Ana but neither moved. The server rode it fine (the stranger in a
DedicatedRoom with two loopback clients walked at its gait); the page did not. A data shard's page has no Mount, so it
never entered a ride, yet the server sent ride words: the predictor waits for a ride the page is about to enter, so it
freed nothing, its ring filled in about a second and the page stopped sending commands. The declared ride now says no
ride words and leads its seated rider (`host.leading`), as a server-only ladder does: the page follows the frames and
keeps sending the reins.
