# MP1.2 bench: bots on the box (2026-11-11)

- `mmo-bots.mjs --bots-on-host`: since J266 the `wildshard-agent` ssh account refuses port forwarding, so `--remote`'s
  `-L` tunnel failed and every bot read lost (opus-cap2). Rather than reopen forwarding, the bots now run on the box
  too, pinned to `--bot-cpus` (default 14-15, the cores neither server nor the replica's 9-13 use), and dial the replica
  on the box's loopback with the same forwarded addresses. Only `mmoBots.mjs` (one bundle, no wasm) goes over ssh; its
  report comes back over ssh before the run's directory is removed. Bot RTT is ~5 ms instead of ~150 ms through the tunnel.
