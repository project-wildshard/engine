# Spawn holds (ONE-FORMAT OF19b)

> Written by: Claude (opus-of19b1)

Dunes' first ray glides held (memory `held` = 1) until the player meets the scout, a runtime plan `holds` row the keeper
applies before it steps. Format 0.47.0 gives a declared spawn the same row (`hold: { field, until }`), so the ray can move
onto the declared host: `installDeclaredHolds` sets the field from the host's flags every step, before the brains, on the
ordinary upload and beside a runtime plan alike. It keeps no state; a shard with no hold registers no step. Format pinned
at 0.47.0 (0.46.2 also admits Dunes' decision pack: a `none` temperament spawn in a `spawnGroup`).
