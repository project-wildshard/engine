# A player beyond the staging Tunnel

> Written by: Codex

> **State:** built, 2026-11-16; TEST-COVERAGE TC45 / XR-4.
> Actual hosted outside receipt and normal exact CI/main land owed.

The existing release-aware bot driver now has one outside-proof mode.
It verifies the signed staging release, requires the public staging
Tunnel socket, and builds the client from that exact release's engine
source. It uses one ordinary address, never private health, SSH,
tailnet or a replica. A unique device/name avoids scheduled collisions.
Candidate HEAD and clean source are checked before and after play;
the report names the candidate and signed release build/serial. The
private room server build is not observed on this public path.

The journey owns its two links. Ordinary movement must move the
authoritative body a metre; ordinary aimed attacks need both an owned
hit confirmation and lower creature health. After dropping the socket,
the same device must resume its body/handle/cell near the same place,
with the damaged creature still hurt and the world ticking forward.
The final leave flag must receive a normal close before completion.
Abort/error paths release their active link and stop the local client.
A failed redial may leave the original body held until normal server
grace expires; such a run cannot complete.

Four explicit real-gateway cases run in 3.37s: CLI routing refusals,
the complete journey, actual damage with a named dropped-confirmation
fault, and cancellation after actual player admission. Fixture placement happens
before the measured player exists; the journey has no host mutation.
The Node proof stays outside hook discovery. Its independent nightly
workflow is report-only for a real green week, with explicit review no
earlier than November 23. Its live receipt is separate from the fast
proof XML; green workflow colour alone is insufficient evidence.

The driver also treats a signalled child exit as failure instead of
turning null into exit0. Existing replica/performance paths retain
their health checks and address rules. No local cook, staging play,
release, deployment or box action was run on the mini.

The existing 11-case bot guard check reads the original copied-fixture
list literally. Name that unchanged base list and append the two new
outside files, preserving both the invariant and the existing check.
