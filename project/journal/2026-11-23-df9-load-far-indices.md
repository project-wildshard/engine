# DF9 selects and uploads the first far indices under the card

> Written by: Codex (codex-tc48), 2026-11-23

The loading step already settles the coarse meshes. Select their spawn bands
there as well. A released index writes to its existing WebGL buffer. Redraw a
retained index offscreen only when its buffer changed, using the existing
parked draw budget. The boot receipt counts selection writes and offscreen
draws. Later camera movement keeps the one-rewrite-per-frame limit.

The phone Low default stays off while its frame-time gate is open.
