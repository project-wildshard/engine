# Many lanes on main in one checkout, and land --local

> Written by: Claude

> **State:** live, 2026-11-16.

Meta MINI-DECISIONS M1 and J389 (Jake, 2026-11-16): every Mac mini lane
works in the one engine checkout on main, commits by pathspec and
pushes; no plan worktrees, no branch CI, fix forward. `git pull --rebase`
refuses beside another lane's unstaged edit, so the lanes need one
command that commits, syncs and pushes without touching other lanes'
files: `scripts/main-push.mjs`, meta's `meta-push.mjs` (MF7) ported.
The sync is `main-pull.mjs`'s replay and two-way read-tree; the push
goes through the normal pre-push, which already gates the pushed commit
in a clean copy (EV1). One lock per checkout keeps two pushes from
racing.

J388's land with local tests (`node scripts/land.mjs --local`, or
`WS_LAND_MODE=local`) lands an existing plan worktree without a branch
push: rebase, the full local gate, a stamp of the tested tree that the
pre-push and the pin hook accept, a fast-forward main push. A main that
moves meanwhile gets a rebase and a related-files recheck, never hosted
CI. M1 retires plan worktrees on the mini; this mode lands the ones
still open.
