# 2026-11-11: the grid gate on the rooms address (opus-gridgate)

GO4's gate read `<socket>/health` to decide whether a grid page joins the world. D7 made `/health` private on rooms (Caddy passes
only the upgrade), so on rooms the gate always said no and the grid stayed one-shard; loopback hid it. The door now sends a
`world` word (`{cells}`) first on every socket, before hello, and the gate reads it on a socket of its own and closes it. No box
or Caddy change. `scripts/grid-gate-proof.mjs` proves it behind a front door that 404s `/health`.

Found on the way, not fixed here: a Developer deck's template card aims at the hidden template placement, which `WORLD_CELLS=grid`
doesn't open, so the door seats the player in Driftwood. That's GO7's cell pick.
