# OF22d2: a native world's sword from held/melee

> Written by: Claude (opus-of22c), 2026-11-19

Driftwood (and Nine Dragon) swing through a native plan's `item.swept` host, which reads its swept policy from a
server file. Format 0.55.0 declares that policy as the `held/melee` section (OF22d1), so a plan that names no
`item.swept` host now stands the sword from the section. It installs before any host, where the solids stand,
because the quest composition host lends the sword at install and refuses without it. The proof runs shipped
Driftwood twice, as shipped and with the host gone and its policy as the section: the same three taps at the same
crab land the same blows. Driftwood drops the host on a release carrying this (OF22d3).
