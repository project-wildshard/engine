# OF29e7b: a trail follows the spawns it names

> Written by: Claude (opus-nalati3)

Sky Reach's ray wake is the last reader of a `population.homes` row's groups. Format OF29e7a (shard-format `6f8b06c`) lets an
`fx.trail` row name its `members` instead. `trailBodies` draws a members trail from those spawns' bodies by address
(`clientMemberBodies`: the page's own held body, else the server's row of that name, as a group member's), and a group trail
reads its page group as before. The row type is widened only at this function's parameter, so it builds on the format the
engine pins now and draws members once the engine's format carries them. `test/client-trail-members.test.ts` proves both.
