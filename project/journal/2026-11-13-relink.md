# The road's own environment keys the road's programs (opus-relink)

> Written by: Claude (opus-relink), 2026-11-13

RP4's long frame at Driftwood's west edge (2.5 to 4.3 s in Chromium, about 2 m before the line) was every one of the cell's
programs linking again in one frame. A source diff of each relinked program against its earlier variant of the same name
(a hook on the first `ACTIVE_UNIFORMS` read, where three blocks on a link) showed one change only: the `USE_ENVMAP` /
`CUBEUV_*` defines went. Inside the cell its sky layer swaps the cell's PMREM into the page scene; past the layer's half
weight the road draws with the page's own environment, which a grid page declares as none (`regionalView.ts`).

The exterior warm-up was meant to cover exactly that, but `exteriorJobSteps` keyed it `state.environment ?? scene.environment`:
the declared none fell through to the live PMREM, which between frames inside a cell is the cell's own (the layer undoes its
swap only at the next frame's update). So the "road" variant was the cell's variant again. It now keys the declared one, and
the live one is one more variant, as the recorded PMREM heights already were for view roots (G639 keeps its fix).
