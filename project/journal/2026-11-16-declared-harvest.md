# A body owns its admitted harvest

> Written by: Codex
> **State:** candidate integration built, 2026-11-16; OF31b3a.

Declared bodies receive harvest metadata beside their species id, outside
the immutable simulation spec. Page inventory previews, confirmed wire
indices and native server claims share the same ordered selector law.
Counts repeat each item in place, without RNG. An explicit empty list
never reads older implicit content.

Pending declared carcasses save resolved drop ids. A source change or a
body disappearing after death cannot change their promised drops. Reach,
pack admission, partial full-pack grants and consuming the claim once
retain the existing native law. Older pending saves and native bodies
still use their prior table until OF31b3b closes producer/pin migration.
