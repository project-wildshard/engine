# Dev hook v4: gameplay soft restart (SHARD-SOURCE AP19)

opus-ss5b, 2026-11-14. `wildshard watch` needed a quest, encounter, spawn or script edit to show without a page reload, and
engine has no in-page level restart (every re-entry navigates). The smallest seam that works: the in-page server already
saves and restores whole worlds, and the client already rejoins a server that came back (the online redial), so the hook's
`restartGameplay` asks the worker to save, boot its world again on the new rows (`withDevGameplay` patches the read shardfile
before the product is made) and take a new link the page's `NetClient.rejoin`s. The page's quest views are the only views cut
from the shardfile at boot, so on a DEVSERVER one-shard page they live in one child scope the hook can replace. Boss panels and
client scripts still read the boot's rows: a later row if a shard needs them live.
