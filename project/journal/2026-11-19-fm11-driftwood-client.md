# FM11 needs the Driftwood client product

The normal Ring 1 pin set keeps only Driftwood's server slice. Its
client catalogue sends the rig's Driftwood link back to the title.
Build the proof once with the same pins plus the playable Driftwood
head. Ring 1 keeps its own existing inputs.

The first hosted run with the product still fell back to the title.
The Ring 1 catalogue moved Dunes into Driftwood's home cell even
when the Driftwood product was installed. Preserve home when its
product is present so the online route can enter the fixture.
