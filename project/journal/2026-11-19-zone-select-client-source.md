# Zone Select reads its room server
> State: implemented, 2026-11-19.
> Written by: Codex

The title starts with the last good list for its world or the baked
staging snapshot. After paint it derives the room address from the
verified release, validates that channel's response, and orders the
existing cards. A 1.5-second deadline covers both reads. Navigation
and the name prompt finish before a fresh result replaces the menu.
Preview can use its baked list offline. Tab layout and fresh-upload
entry follow in ZS10 and ZS11.
