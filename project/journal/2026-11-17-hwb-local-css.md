# Show CSS errors in the local land gate

SF74 W1, in SHARD-PLATFORM's archived Wall-clock mini plan, reserves
the local full suite for the push gate. The J400 hook supplies the
override through its own environment and acquires a real test lease.
It can also reuse an authenticated full proof for disjoint main changes.

The HG4 attempt acquired its lease and returned before Vitest. The CSS
checker on that tree found 26 quest class prefix errors. Git put the
diagnostics on its porcelain stdout, so land reported the lease ending.
Engine main fixed those classes in `dc0304da2`.

Strict CSS errors and their RED summary now go to stderr. The real Git
fixture proves a clean local push gets its lease without a caller
override. Its red CSS case first reproduced the HG4 symptom, then proved
the error was visible, later gate steps stayed off, and main stayed put.
