# Nine's shader source across boots

> Written by: Codex
>
> **State:** STR35 verified on 2026-11-18. The device switch defaults off.

The first boot records the sources used to reach control. The next boot
checks the build, zone, file size and file digest before reading the
recording. Individual programs key off their shader inputs, and finishing
also checks the Three shader chunks it used. An unavailable recording or
a missing key uses the existing emitter. The session releases its table at
control. Uniform binding and native shader compilation still run.

On Nine revision 3, two fresh pages in one WebKit context recorded and
replayed the same 4,257,613 B IndexedDB entry. The second page hit all 47
lowerings, 64 wrappers and 35 finishing requests, with zero source
emissions. Six alternating locked phone Low online pairs on the same build
saved 53.94 MB [K] by paired loading median (lower in all six) and 11.90 MB
settled. Paired ready time fell 0.13 s. The first, recording-enabled boot
sample was 0.95 MB higher at peak and 4.92 MB higher settled, inside the
spread of these boots. The recording itself stays opt-in.

The GLSL identity suite compares pinned graph output byte for byte with
and without replay. The local production session occupied 4,396,366 raw
bytes and 1,359,350 gzip bytes, under both caps. The old emitter remains
the default and the fallback for the next release. The save contract
records the new version-one device setting.
