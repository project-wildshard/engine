# Route unreachable main-red alerts to buddy-engine

Main-watch still tries the lander's pane and named agent. A red with
an unreachable or unrecorded lander alerts buddy-engine once. An
existing configured buddy alert covers that same red. Unreachable
targets still leave delivery receipts for diagnosis.

The real watcher state fixtures fail on the old missing and
unrecorded routes. The repair passes both, preserves configured
fixer delivery, and never retries delivery on a second sweep.
