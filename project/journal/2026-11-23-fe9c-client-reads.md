# FE9c: the page reads no original

> Written by: Claude (opus-compat-w6), 2026-11-23

The page plays cook output (cooked from the chain's copy when this validator
refuses an original, CP1) or pinned folders (admitted through the same chain,
FE9b), so it needs no chain of its own. A test holds it: no client file opens
a tarball, validates or migrates a shard file, or fetches the API's originals.
