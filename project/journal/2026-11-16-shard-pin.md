# Shard pin workflow (opus-publish1, meta SHARD-PUBLISH-ACTIONS SP6)

- J369 lets the Mac mini ship shards; a shard repo's publish.yml now
  uploads from Actions. The pin bump that used to follow by hand
  (fafee64e) is `scripts/pin-shard.ts`: it moves one slug's row in
  shardfiles.json and the pinned catalogue document, then refreshes
  staging.json. A full `pins.ts refresh` would drop hand-pinned
  staging revisions, so it moves only the published slug.
- `.github/workflows/shard-pin.yml` runs it on dispatch, mirrors the
  tarball on `pins`, pushes `plan/pin-<slug>-r<N>` with the nightly
  app token (so CI runs) and opens a PR. Landing stays land.mjs's.
