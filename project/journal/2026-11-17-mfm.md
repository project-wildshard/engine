# 2026-11-17 MMO failure modes (opus-mfm, plan/mfm)

- FM6 mode 44: pickup packs were a bare fetch + hash check, so a truncated pack ended the
  load on "Something broke". They now go through `readContent` with exact length and a
  `verify` (hash) port: a bad file is a broken read (reload retry, then the card's RETRY,
  `packs-5xx pack-broken`). Surprise: after the heal RETRY still got the truncated bytes:
  the HTTP cache kept the 200. Every read after any failure now uses `cache: 'reload'`.
