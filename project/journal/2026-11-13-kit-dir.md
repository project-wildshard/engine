# The kit moves out of src/ (K11, J329)

repo-kit v3 keeps its own tooling in `kit/`: the tsconfig, the oxlint
and oxfmt configs, and the asks, md-wrap and herdr scripts. Engine's
code stays in `src/`, including `src/cli`, `src/test` and
`src/scripts/check-sides.mjs`, which are engine's own.

- `kit-dir-move` moved the stamped files and repointed package.json.
  `kit.mjs apply` and `agent-sync` also wanted to bring in the REPO-DISK
  DK7/DK8 pieces (scratch-end, tmp-measure, pinned-links), which engine
  has not taken yet and whose tests fail here (no `scripts/scratch-dir.mjs`).
  So the hooks, skills and githooks keep their HEAD bytes with only the
  `src/scripts` to `kit/scripts` repoint; DK8 stays its own row.
- `src/tsconfig.json` extends `../kit/tsconfig.json` with the old
  include list, so `src/client/tsconfig.json` (`extends ../tsconfig.json`)
  still finds its base one level up.
- `src/.oxlintrc.json` extends the kit config with `src/`'s own ignores.
  `lint:kit` and `lint:fix` are two `lint-cli.mjs` runs, kit's config on
  the root without `src/` and `src/`'s config on `src`, because the kit
  config's overrides (`e2e/**`, `**/*.test.ts`) now match from `kit/`.
  Engine keeps `lint-cli.mjs` rather than `kit/scripts/lint.mjs` for its
  pinned tsgolint. `worktree-ignore.test.mjs` runs each segment.
- `.prettierignore` gains `src/scripts/**` and `src/**/*.md`, the paths
  the old `src/.oxfmtrc.json` skipped (oxfmt refuses `..`).

typecheck:kit, lint:kit, format:check, check:agent-sync, check:parity,
