# WIRE-STABILITY WR7: the saves contract (opus-wr7)

- Whole-document saves. `saves/shape.ts`: `known` parses only the fields a schema
  names, `keepUnknown` puts the stored document's other fields back on write, so a
  read-modify-write by an older build keeps a newer build's data. Strict persisted
  save schemas are now `looseObject`; shared strict schemas inside them are covered
  by `known`. A same-version parse failure is reported with `contract: true`.
- PlayerDoc: a newer server's doc throws `SaveNewerError` (door answers `retry`),
  and `save_version` in the upsert's `where` stops an older server's checkpoint
  landing on it. Same-version unknown fields ride through seat and write
  (`carryDoc`). A same-version doc that fails goes to `save.contract` and Sentry.
- `src/shared/engine/saves/saves.lock.json`: every persisted key's version, shape
  hash and migrations (81 keys). `test/saves-lock.test.ts` fails a shape change
  without a bump, a bump without `migrate[v-1]`, a lower version or a dropped key,
  against the committed lock and main's. `pnpm check:saves` runs it in pre-push and
  ci-static. Refresh: `SAVES_LOCK_WRITE=1 pnpm exec vitest run test/saves-lock.test.ts`.
- Whole-document pin `test/pins/saves/documents/epoch-1.json` (v0.1.8): every local
  key's document plus a real PlayerDoc; `released-save-play` loads it with no
  `.corrupt` key. WR8 recaptures it at epoch 2 (`SAVES_PIN_WRITE=1`).
