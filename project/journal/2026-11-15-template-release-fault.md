# A real release 503 heals into the Template

The browser begins a real title/Shard-select entry while the existing
chaos proxy serves 503 for the signed release. The test requires a matched
request and the release-5xx page, heals the proxy, uses Try again and
waits for actual Template control. Only the deliberately injected 503
console lines are admitted; page exceptions remain failures.

The focused Chromium proof passes in 23.9 s. The pending entry stays owned
on both success and early assertion failure, so it cannot leave an
unhandled rejection when its context closes.
