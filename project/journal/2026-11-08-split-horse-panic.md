# S6: a bitten mount really panics

A real mounted wolf encounter reproduced four rider-bitten signals with
the authoritative ride's panic timer still zero. The signal relay alone
was insufficient: the server never activated the existing rear/bolt law.

The mounted owner now consumes bite/scare/lightning signals through its
authored panic duration rule. A bite applies only to the nearest victim's
seat; distance-based scares still use each horse's own position. The
existing 0.5 second rear, panic bearing, spur reset and jolt are shared in
MountedBody.startPanic. This changes no collider or movement tuning.
The wired page presents its feedback and follows the replicated clocks;
it no longer starts a competing page-owned bolt.

Three fresh boots per browser passed in Chromium and WebKit. In each,
the actual camp-horse Mount prompt succeeded, a living wolf bit the rider
for 12 HP, and both server and page panic clocks became positive. The
server's observed peak was 0.883–0.900 seconds. No damage, signal, clock
or creature state was set by the proof. Only the player was placed to
reach the real encounters. S6 is repaired, not struck without evidence.

The public nalati-signals play selector includes this check. Types and
lint pass; the focused eligible checks passed two tests in 341 ms.
The guardian's separate natural-raid proof remains running, and the
