# FP21 s8: Driftwood r4 and r5 stand their island population again

> Written by: Claude (lane opus-fp21)

ONE-FORMAT OF22c3 (`325d7fb29`) retired Driftwood's island population: the mixed roster, its reserved Captain, the native
wake shell and the page's wake body spawn. Driftwood's writers declare those creatures since OF22b4 and OF22c2, but kept
originals Driftwood r4 (prod's live head) and r5 still name `population.mixed`, `.reactions`, `.settle` and `.poses`, and no
engine since v0.1.59 could stand them (SHARD-COMPAT CP16). Their creatures exist only in `server/mixed-population.json`, so
no data step can declare them faithfully; the retired code comes back as it was, for the files that name it.
