# Driftwood's quest hosts read declared bodies (ONE-FORMAT OF22e1)

> Written by: Claude (opus-of22e), 2026-11-19

`quest.kill-steps` and `quest.composition`'s sword guard read only the mixed population (`run.island`). Once
Driftwood's sailors, crabs and monkeys are declared spawns (OF22b1) and its plan drops `population.mixed`
(OF22b4), a kill would file nothing, the guard would never hold, and both hosts refused to install with no island.
A declared body now counts as its species row's kind (`declaredQuestBodies.ts`): kill steps read the island where it
stands, then the declared bodies; the guard reads both, and the island only when the plan names one. The test
declares a converted strider as a `sailor` on the shipped Driftwood product and kills it: `dead:sailor` files.
Driftwood's OF22b4 needs this in its engine pin (v0.1.54), with OF22c2's declared Captain for the chapter wake.
