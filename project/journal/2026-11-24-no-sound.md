# No sound from agent runs (meta QA-FEEDBACK-2026-11-24 row 49)

> Written by: Claude (lane opus-ops2). 2026-11-24.

A lane booted the iOS Simulator for a Driftwood fps run and its WebKit played game audio on Jake's speakers; Jake:
"NEVER FUCKING SOUND SOUND OFF". Two guards. The shared PreToolUse hook `.agents/hooks/no-sound-guard.mjs` (repo-kit
`509d73a`) refuses booting or driving the Simulator, a Chromium binary run without `--mute-audio`, `playwright
open`/`codegen`, agent-browser args that drop `--mute-audio`, `open` of a game page and `afplay`/`say`;
`ALLOW_AGENT_SOUND=1` is the J381 hatch. The marked browser helper (`browser-playwright.mjs`, which every agent launch
takes for its actor marker) now also silences: a Chromium start always gets `--mute-audio`, and every context and page,
WebKit and Firefox included, runs `scripts/browser-silence.mjs`'s `silencePage` first, so Web Audio plays into a zero
gain in front of the speakers and media elements stay muted. `test/tooling/agent-browser-marker.test.mjs` covers both.
