# The npm bin runs from node_modules

- The packed `engine` bin pointed at `src/cli/main.ts`; Node refuses to strip types under `node_modules`, so the
  command crashed from an npm install (found when 0.1.15 published, NPM-PUBLISH). The bin is now
  `src/cli/engine.mjs`, which loads `scripts/format-hook.mjs` (J82) before importing `main.ts`.
- `src/cli/bin.test.ts` packs the repo, extracts it into `tmp/…/node_modules/@wildshard/engine` and runs the packed
  bin: red on the old bin, green on the new. A real `npm install` of the tarball runs `engine --help`, `--version`
  and `serve` too.
- Not fixed here: the other ~990 `.ts` export targets still need the format hook (or Vite) when Node loads them from
  `node_modules`, and npm ignores pnpm's `&path:` in the `@wildshard/wire` dependency.
