# Share bounded lifecycle and output checks

> Written by: Codex

> State: built, 2026-11-15.

Six suites own their loading traces, release metadata, inspector
socket doubles, ground-hold requirements, JSON products and icon
outputs. They close drivers, release tile requirements and remove
temporary outputs without replacing shared modules or global state.

All thirty-seven cases pass alone and in exact forward/reverse shared
orders. Warm isolation costs 2.526 CPU-s; shared orders cost 2.045 and
2.086 CPU-s. The initial cold sample is 3.710 CPU-s. This is local batch
evidence, not a full-gate saving or proof about the other isolated files.

Large TypeScript program-building suites and shader-state mutation
suites remain isolated rather than broadening this audited cohort.
