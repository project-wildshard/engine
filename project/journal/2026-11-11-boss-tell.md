# TEMPLATE-E2E TE-ENG1: a rows-only boss tell and damage window (opus-bosstell)

Why: the Template bosses (Mossgate's Barrow Warden, Brasscap's Dust Wyrm) must be rows plus a decision script, no
native code (Jake). Pine's Antler King does its ring tell and weak-core window in native code (`tellRing`,
`damageMul`); a decision had no way to show a tell or to gate damage. Two small general verbs close it.

- **Scene field from a decision.** `Do.field(0, Field.x, v)`: the `field` command on target 0 writes the scene's
  public shared field (the field must be in the script's `fields` capability, bounds as declared). Panels and
  colliders already read shared fields, so a ring panel shows on the tell field and a core panel on the open field.
  `DeclaredScriptWorld.writePublicShared` is the trusted write; the scene lane's checkpoint carries the value.
  A shard with no scene lane refuses the command (`scene field owner`).
- **Encounter guard.** `Do.encounter(4, guard)` on a PhaseEncounter: 0 open (default), 1 shut, 2 melee hits only
  (`dmg.melee`: sword, spear), 3 the rest only (shots, arrows). Reset to open at each checkpoint reset and at victory;
  saved as an optional `guard` in the encounter continuation (absent when open, so old saves are byte-identical).
  The boss bar's shield stays the beat shield only (Codex review: one source for local and room bars).
- No format change: both verbs ride existing ABI v1 commands. Pine and the other native bosses are untouched.
- Test: `test/boss-tell-window.test.ts` over fixture modules in `test/fixtures/boss-tell/` (rebuild with its
  `build.mjs` and a sharddev checkout; engine's suite has no AssemblyScript compiler since the lift).
