# Engine reads format 0.79.2

Meta QA 11-24 row 70 (opus-nalati). Engine pinned format 0.78.0, whose grass schema still required the card clumps, so
a shard without them (Nalati's) stopped at `level.world` with "Expected cards" even though engine `ed8aef5fd` draws grass
without them. Format 0.79 makes the cards optional; it also deletes `requires.sdk` and the old grid pointer, and the legacy
SS3 Brasscap copy (J507: no stored zone in tests).

- No live pin carries a deleted field (all 27 checked), so engine's readers need no mend; made-up fixtures drop
  `requires.sdk`. The frozen worker fixture keeps it: its pin hashed it.
- Format 0.79 ships no whole Brasscap (the export omits the world GLBs), so `pins.ts install --from-format` has nothing to
  admit. Tests and the cook-cache proof take a whole Brasscap from `wholeBrasscapProduct()`: the format's copy while it
  ships one, else the tracked pin's shard file by hash from the pins cache.
- The version-contract test's preceding product is a live pin at an earlier format (0.1.0.4); the old `version`
  envelope's alias test left with its last product.
