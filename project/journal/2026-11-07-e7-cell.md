# Share the E7 cell world

E7 opens the same world as a standalone grid, with per-player ownership
and facts. Extract the cell world into the server host and preserve the
engine's refused-save progress recovery at its new boundary. The data
and native paths both keep their original progress semantics.

Join the current creature rewards with E7's OwnedBook. Install the
reward world hooks once; each seated player's goods remain separate.
Keep finishes out of every player's inventory, including receipt
recovery. The real reward filing reproduced an erroneous inventory
item before finish ids were supplied to per-player goods.

The source's two changed shard-source tests had been retired in the
engine lift. Keep that retirement. The additional rider checkpoint
proof now uses pinned Nalati bytes in dedicated-rewards instead.
Other E7 game changes retain per-seat quests, respawn and standing
fight looks. No new rendering or shader design is part of this port.
