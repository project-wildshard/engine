# Template test helpers use the seated world

The suite waits for Template 1 gameplay and reads position, health and
quest flags from the active probe. Named poses resolve the validated pin's
POIs, not copied coordinates. The fixture's Template placement is the
origin cell. Harness placement tells the worker server about the move.

The browser proof checks a named Lamplighter pose and a missing-name
refusal against a real seated world. Every context installs deterministic
harness pins before any game module runs.
