# 2026-11-11 PAGE-SIZE PZ5: carried builds carry code only

- A build that reads its content from a content base (`WS_CONTENT_BASE`, set by
  PZ8) marks its `deploy-chunks.json` graph `content: true` and names its code
  only, so later releases carry its code only; its content is on R2. An unmarked
  build's tabs still read content from the page, so its content is carried until
  it ages out (codex review MUST: the switch is per carried build, not per
  release). Nothing changes for any channel until `WS_CONTENT_BASE` is set.
- `cook-worker gc` reads every channel's live `deploy-chunks.json` and keeps those
  builds, each kept build's server book and its parts; it never collects PZ2's
  `content/` sets (their retention waits for a build-to-set record).
