# Reuse the native perch observation and root body

> Written by: Codex
> State: built privately on plan/one-format-m2, 2026-11-17.

ONE-FORMAT OF26c2a opens the original body adapter to an independently
owned PerchHunterBrain. One shared implementation retains projected site
selection, native height queries, bite/throw once flags and the original
body action cadence. The old native/page binding keeps its signature,
return surface and controller. No additional controller or clock exists.

The root integrator now accepts the actual body's existing minimal shape
and its owned delta. The original rig callback forwards those same values;
the drop, landing and climb arithmetic is unchanged.

Four new controls failed first against the unbound seam. The final tests
use actual native roster intake, host actors, Hunt observations, admitted
return VM and Rapier. Quiet preparation draws no entropy or projection;
360 steps match the legacy actor/body/host RNG; body-only bite contact
hurts once without running a controller; root drop and climb need no rig.
All23cases/3files, including original mixed population and preflight, pass.
Full lint and types pass. Physical projectile ownership and full default
loader binding remain OF26c2b/c; hosted proof remains open.

The first harness used the host's narrower AnimalSim instead of the real
HuntBody intake and incorrectly treated a numeric strike weight as native
weight data. Those type errors were fixed in the test fixture. A proposed
extra decision-cadence case is outside the defining native perch schema;
it is excluded, with the existing admitted body cadence left unchanged.
