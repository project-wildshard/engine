# MW5: bots ride the next staging release

> Written by: Claude (lane mini-mw5), 2026-11-24

The plain restart proof (`--restart-proof`, 2026-11-23) heard no countdown: J174's countdown runs only when a release moves
staging (`ReleaseWatch` sees a higher serial, `World.beginGrace`), and engine releases are the MacBook's (J482). Jake chose
"Bots ride the next release". `mmo-bots.mjs staging --release-proof` seats 3 bots by default (one of the address's 4 sockets
stays free for the mini's own staging checks) and holds them up to 14 hours, seating again after any drop or plain restart.
When a countdown arrives the fighter hurts a creature inside it, the parent reads the signed release file (the bots'
preload), and after the restart every bot must come back to the countdown's build within 2 m with the same owned lines.
It builds once, so the shared checkout may move while it waits.
