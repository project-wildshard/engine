# Match the API's identity record to the unchanged original

The versioned staging cook refused Driftwood 0.0.13, Far Reach
0.0.10 and Mossgate 0.1.23. The API called each copy identity.
The cook recorded the canonical chain even when it ran no steps.
Direct proof on all three exact files found zero applied steps and
matching API and cook digests.

The cook accepts identity only after both checks hold. It still
refuses any mismatch with a recorded non-identity chain or digest.
