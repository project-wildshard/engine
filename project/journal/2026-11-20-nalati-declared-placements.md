# Read declared placements at the roster's birth point

The riding roster can borrow placements explicitly marked in its adoption
ledger. The ordinary creature host skips those rows so each creature is
born once. The existing birth point keeps the saved body order, body
clock, herd membership and adoption stream.

An authored uint32 spawn seed represents the exact draw that the riding
roster originally consumed as a fraction. The older baked roster format
still reads as before.
