> Written by: Codex
> State: built locally, 2026-11-16; ONE-FORMAT OF31d3b2c2.

The source adapters now compile old cap aliases into exact tags. Player
rule installation validates that bounded contract once and constructs a
set; the hit path only compares existing request/state/effect tags. It
never expands a creature name. The page adapter uses the defining compiler
for older admitted fight metadata. Environment ownership, explicit flags,
boss and dodge ordering are preserved.

Sword no longer selects shell, wood or sand by kind. The generic swept
view reads the authored move's default and row overrides. A move without
debris draws no contact particles. Hit-stop, damage, rewards, wire labels,
iron sparks and heavy scaling retain their existing generic execution.
The old callback port has no production caller besides Sword; normal
producer migration supplies the old content as explicit move data.

Four cap controls failed on the previous reader. The particle-absence
control then reproduced the old fallback before removal. Afterward, 37
normal combat, harvest and wire controls pass, including the actual native
item fixture's shell9/wood8 and iron10/heavy16. Types and game lint pass.

producer/fixture proofs and exact hosted CI must finish before landing;
