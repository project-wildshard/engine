# Mirror Salt find rewards

> State: 2026-11-20. MSZ38 engine support.
> Written by: Codex

The ivory land-sail is a separate per-player kind. Its dock reads the
player's own completed-quest flag through the same quest book that sends
the page's phases. Both a direct spawn and a normal claim require the
flag. The test gives the flag to one of two players and checks the
client prompt and the native server claim.

Pennants and chests write owner-scoped script fields. Grid prompts read
those owned lines, as their panels and the standalone prompts already
do. The format and SDK prerequisites qualify these rows in the local
Mirror Salt build.
