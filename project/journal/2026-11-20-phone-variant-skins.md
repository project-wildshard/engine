# Phone variant skins

> Written by: Claude

ONE-FORMAT OF23f. Pine's creatures are variant skin looks, and a variant look
had no phone skin, so phones loaded the desktop creature maps. The format now
admits a phone variant table, and tier selection leaves the desktop skins out
of the phone's files. The client resolves only its own tier's skins, so on a
phone it never asks for bytes it did not fetch.
