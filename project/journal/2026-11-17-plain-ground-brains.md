## OF26a: skirmisher

A plain upload could declare the original skirmisher or stalker alias but
refused its missing native port. Ten real-server cases fail before this
change. The same ten pass after installing the stock server recipe; both
captured native-controller controls also pass.

The original controller owns decisions, actor memory and attack duration.
The existing memory-action helper claims the original hit flag before a
stateless StrikeRunner contact on that body clock. There is no second
strike clock. The selected admitted strike supplies shape, tags, damage
and windup. Invalid contact timing and missing strike authority refuse
before callbacks install. One actual contact pays7damage exactly, never
the body's unrelated12damage tuning, and a miss cannot pay later.

Perception uses actual players and host attack permission. Authored social
membership supplies the native leader/subordinate observation; unrelated
leaders cannot scatter an actor. Membership arrays are built once per host
and shared in authored order. No kind name or guessed herd is introduced.

The server composes this recipe beside the shared data host. Shared code
never imports the server plugin. The installer lends its parsed declaration
as an optional third argument: existing two-argument injected recipes and
calls remain compatible. Native policy contracts and actor/RNG continuation
remain unchanged. Default-loader and exact restored body/health/controller/
RNG tests run against the real simulation, with no injected test recipe.
