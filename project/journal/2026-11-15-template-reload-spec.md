# Template 1 saves its real door flag

The save spec resolves the hut POI, opens its door through E, waits for
the worker save, reloads the document and re-enters through Shard select.
It reads the server's door quest flag on both sides of that reload.

The common title-entry helper also dismisses the resumed page's drop
card, matching the existing Template 2 smoke's reload path.

The hut POI is above the interaction point, so the spec starts four metres
outside, faces the door and walks two metres toward it before using E.
It checks the physical panel as well as the earned flag. The fixture now
uses the original HUD entry operation and waits for 30 worker frames;
its play cap is reapplied after grid navigation clears query options.
Only a shown, non-inert pause menu is a Resume target.
