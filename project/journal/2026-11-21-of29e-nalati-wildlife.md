# OF29e (Nalati): wildlife stands from its files

> Written by: Claude (opus-nalati2)

Nalati names its client wildlife population in its plan (`population.wildlife`, with a shard-named frame). Following
OF29e1's server family, a plan that names no wildlife row now stands it from `actors/wildlife.json` and the sheep crowd
files, in the engine's frame `engine.population.wildlife` before `engine.creatures.update`. Unknown `after` ids are
ignored by `sortSystems`, so registration order keeps it behind the boss as Nalati's row did. A plan naming the row keeps it.
