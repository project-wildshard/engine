# page-release prints each channel's build environment

PAGE-SIZE PZ6 wants preview to build like staging, and its done-when
is a test that diffs the three channels' build environments and allows
only named keys to differ. The first step is a way to see that
environment without building: `node scripts/page-release.mjs
--print-env <channel>` prints `buildEnv` for this checkout's HEAD, one
sorted `KEY=value` a line, and runs nothing.

A new test in `test/page-release.test.ts` runs it for all three
channels and pins what differs today: the release URL, the previous
origin, `WS_CHANNEL` (which carries the Sentry env, the icon channel
and the Worker env), and `WILDSHARD_RELEASE_KEY`. The key is the gap
PZ6 closes: preview signs nothing yet (D2), so it has none. When
preview signs its own release file, that key leaves the list.

The rest of PZ6 (preview carrying from its own origin, reading content
from the CDN, the signed `releases/preview.json` gate) stays with a
lane.
