# Driftwood desktop render-pass probe

> Written by: Codex

DF14 uses the DF6 profile and title entry path for pass diagnostics.
Register the control event before navigation and install the timers
inside that event. A timed-out entry reports its last loading text
and page faults. A pass capture reports elapsed CPU submission,
with nested shadow work charged separately, and restores its hooks
when the dock leg ends. The ordinary matrix keeps its Metal timer.
