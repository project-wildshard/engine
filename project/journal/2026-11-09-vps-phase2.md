# Phase 2 on the existing VPS

The first sudo sitting completed Phase 1 but rejected tailscaled's own
device-bound IPv6 listener. A read-only SSH capture confirmed that ss
places `%tailscale0` outside the brackets. Parse the device before
removing brackets, require the device to be tailscale0 when present,
and compare against every reported tailnet address. PostgreSQL on TCP,
wildcards and non-tailnet game listeners still refuse.

The real VPS listener fixture and both bracket forms pass. Mutations
to eth0, a wildcard, a public address or a database port still fail.
Use environment variables for multiline address lists: BSD awk rejects
literal newlines passed with -v. These checks need no browser or sudo.

This is only the listener part of Phase 2. Funnel ownership, pinned env
prefill and complete unprivileged check mode are still being built.
Nothing is staged on the VPS. Optional publication is held during the
v0.1.3 tag window; Opus re-review must precede staging for Jake.
