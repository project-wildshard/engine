# NB10: the save fixture follows the pin

> Written by: Claude (opus-compat-w4), 2026-11-22

A re-pin left `test/pins/saves/<slug>.json` naming the old hash, and released-save-play went red until a hand
follow-up moved it (Nine r6 `32236ee94`, Pine `b93a7c5e8`, Nalati r6 `211ba9d49`). `pin-shard.ts` now moves it
in the pin commit (`moveSavePin`: a refused save stays refused on the new pin; a save built on the new hash drops
`pin`; otherwise `pin` names the new hash), and `shard-pin.yml` adds the file to its pathspec when it exists.
