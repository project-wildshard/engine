# The world's word, kept a minute, outlives the page (opus-wordkeep)

> Written by: Claude (opus-wordkeep), 2026-11-13

`worldWord` keeps the door's word a minute so the title, a `?chunk=` page and the grid page share one socket (the door allows 10 a
minute per address). Its keep was a `gridGate` session save in `online.js`'s own store, which has no storage (OF4 found the same for
the release file), so the word lived in memory and every page load asked the door again. `test/world-word-keep.test.ts` proved it:
two page loads, two sockets.

Now the page lends its keep, as `clientWorker.ts` lends `release.kept`: `oneWayIn.ts`'s `tabWordKeep()` is the same `gridGate`
session save in the page's store (its lock key is unchanged), and `readHosted` passes it to `worldWord`. The minute holds: a page a
minute on asks again. A caller that lends no keep keeps the word for its module realm only. The keep stays per tab, as the comment
always said; OF3's device `gridRoute` is a different keep (the fallback when no word comes) and doesn't cover this.
