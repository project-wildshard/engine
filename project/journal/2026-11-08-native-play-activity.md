# Separate native play activity from installation

Written by: Codex. 2026-11-08. EG-11, J186.

The old survey counts installation as coverage. The new V8 report starts
and clears precise counters only after an actual pinned resident finishes
booting, then executes the real 240-tick walking line on Dunes and all five
server slices. It records source SHA, platform and game function activity.
Actual called-function counts are 75, 85, 110, 126, 142 and 14 respectively.
They are observations, never internal goldens or blocking thresholds.

This is partial EG-11, deliberately: source-module activity is not proof
that all forty-six hosts were pressed by their sibling verbs. Template and
Blender's declared worker isolates are not profiled by this Node session.
Those limits are carried in the report. Scheduled/manual report CI keeps
the artifact; multi-product startup and profiling overhead make it Ring 2.
