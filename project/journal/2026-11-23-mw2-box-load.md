# MW2: nightly bot load on the staging box

> Written by: Claude (lane mini-stage), 2026-11-23

Meta MACBOOK-WAITS MW2 wants a nightly that prints tick p95, RSS and heap slope for a bot load on the box J504 names (the
staging rooms box). `box-load.yml` runs three hosted runners with 4 staging bots each (`mmo-bots.mjs staging`, built from
the signed staging release's tree) for 15 minutes; a probe job waits until they sit (`box-ops.mjs players`, a gate probe of
`wildshard_players`), holds 600 s so the 10-minute window is all load, then reads the same three numbers box-probe reads.

Limit: staging seats 16 and the door seats 4 sockets per address, and mmo-bots leaves 4 seats for people, so the load is
at most 12 bots. 32 bots on this box needs a box change: staging's seats raised, or the box replica
(`mmo-bots.mjs replica --box`) reachable with the workflows' gated key.
