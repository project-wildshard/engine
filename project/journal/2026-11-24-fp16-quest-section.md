# FP16: the quest family from quests/server

> Written by: Claude (lane opus-native)

The engine half of FORMAT-PRUNE FP16 (ONE-FORMAT OF17b3): a native plan that names no quest host stands the four quest
hosts from the `quests/server` section, after the plan's hosts. Read untyped and admitted by the pinned plan schema, so
it lands before the format cut that names the section. Driftwood r10 and Pine r13 run digest for digest either way.

FP16d (Nalati, first host): a plan with no `day.*` host and no toon, keyed or `world/days` clock stands its day from
`world/forest-weather.json` `sky.clock`, as Nalati's `day.declared` read it; Nalati r7 runs digest for digest without the row.

FP16 every host: `server/riding`, `server/boss`, `server/patrol` join `server/quest`; the plumbing stands with the quest
family, `collision` with a bake read whole, and a derived list takes one install order (the three pins' own). Driftwood r10,
Pine r13 and Nalati r7 each run digest for digest with a plan naming no host.

FP21: a product may ship `server/world` (format `40da84e`) in place of `server/native-assembly.json`, never both; the three
pins run digest for digest with no plan file.

FP21: the host ruler reads hosts from the server sections and `server/world`, so a product with no plan file is measured.

FP21 delete (branch plan/native-fp21, unpushed): one path. A world stands its hosts from `server/world` and the family
sections only; a kept plan file (CP16) is admitted read only by migration into them, and refused if it names a host no
section holds. `test/no-native-plan.test.ts` fails while a pin ships the plan file (Driftwood r10, Pine r13, Nalati r7).

FP21 s1 to s8 (opus-fp21): a kept plan file no longer migrates into the family sections, where 11 of the 20 kept originals
named a host no section held. It runs as stored, in its own order, and `keptHostHome` names each host's home: a family
section, a host the engine stands with no row, or the kept home of the chain step that moved it (s1 population, s2 day,
s3 water, s4 weather, s5 held, s6 collision, s7 traversal, s8 the island population). `test/kept-native-plans.test.ts`
holds every host of the 20 to a home.
