# SR2: the owner's settled contact has feel

A real worker bear blow took HP from 100 to 55 while the page produced zero flash, grunt, combat lift, shove or arc. NetHit now carries a blow bit from the actual damage request's feel.blow tag. The owner's page sends that contact directly to PlayerHurt's existing presentation ports; it does not call the damage pipeline. The schema hash after this row is 281205394, so old clients cannot silently decode the new bit order.

The real dry-ground fall probe also exposed a second page hit: incomingCap only capped hostile damage, so the predicted landing still wrote eight page HP. PlayerHurt now keeps landing feel while a linked page leaves the health write to the worker. The actual fall then produced one flash, eight server damage, zero page damage, zero grunt/shove and no directional arc. The bear produced one flash, grunt, combat lift and shove, an arc, and zero page damage.

The direct presentation method shares the old blow implementation rather than recreating its effects. No rendering or UI layout changed. The old unused test/fake/legacyHurt.ts is already absent from this engine tree. Named network checks passed 5 files and 31 cases. Chromium and WebKit repetitions are opt-in play flows, outside the hooks. Publication remains held for v0.1.1.
